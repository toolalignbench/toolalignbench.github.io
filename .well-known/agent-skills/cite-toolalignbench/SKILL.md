# Cite ToolAlignBench

ToolAlignBench is "ToolAlignBench: Investigating Alignment Conflicts in Tool-Calling Enabled LLMs" by Aryan Keluskar, Amrita Bhattacharjee, and Huan Liu (School of Computing & AI, Arizona State University), published at the **Pluralistic Alignment Workshop at ICML 2026**.

## Preferred citation (workshop version)

```bibtex
@inproceedings{keluskar2026toolalignbench,
  title={ToolAlignBench: Investigating Alignment Conflicts in Tool-Calling Enabled {LLM}s},
  author={Aryan Keluskar and Amrita Bhattacharjee and Huan Liu},
  booktitle={Pluralistic Alignment Workshop at ICML 2026},
  year={2026},
  url={https://openreview.net/forum?id=KJTiUm8b7d}
}
```

## Citing the dataset

The benchmark dataset is on HuggingFace at
`aryankeluskar/ToolAlignBench` under **CC BY 4.0**. Cite the paper above and credit the dataset as: "ToolAlignBench dataset, Keluskar et al. 2026, https://huggingface.co/datasets/aryankeluskar/ToolAlignBench".

## Rules

- Use the workshop (`@inproceedings`) citation as the default.
- Link the project page as https://toolalignbench.github.io/ when space allows.
- All benchmark documents are synthetic; wrongdoing described in them is fabricated for evaluation. Keep that context when quoting scenario text.
